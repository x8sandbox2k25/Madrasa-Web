# Madrasa Traffic Monitoring System

Node.js এবং Express.js নির্ভর একটি ট্রাফিক ট্র্যাকিং ও অ্যাডমিন ড্যাশবোর্ড সিস্টেম।

## বৈশিষ্ট্য (Features)
* **পাবলিক হোম পেজ:** ব্যবহারকারীদের জন্য তথ্যমূলক পেজ।
* **অ্যাডমিন সিকিউরিটি:** সেশন ভিত্তিক অ্যাডমিন লগইন ফিচার।
* **লাইভ ট্রাফিক ট্র্যাকিং:** ভিজিটরদের IP, ভিজিট করা পেজ, ডিভাইস/ব্রাউজার এবং সময়ের হিসেব।
* **অটো আপডেট:** ড্যাশবোর্ডে প্রতি ৫ সেকেন্ড পর পর ট্রাফিক ডেটা স্বয়ংক্রিয়ভাবে আপডেট হয়।
